# 점진적 단계별 개발(Stepwise Implementation) 수행 지침

이 스킬이 호출되면 절대 전체 애플리케이션을 한 번에 모두 작성하려고 시도하지 마십시오. 반드시 아래 절차를 엄격히 준수하여 **한 번에 하나의 Phase만** 완수하십시오.

## 작업 수행 절차 (Workflow)

1. **진행 상태 확인**:
   - 현재 작업 디렉터리의 `progress.md` 파일을 읽고, `- **진행 상태**: [ ] 미완료`로 표시된 **가장 첫 번째 Phase**를 확인합니다.
   - 상단의 `[공통 아키텍처 및 환경 호환성 규칙]`과 해당 Phase의 `세부 구현 항목`을 숙지합니다. (특히 모든 경로는 `./presets`, `./data`, `./nas_archive` 상대 경로를 사용하십시오.)
2. **단계별 코드 작성 및 증분 업데이트**:
   - 이전 Phase에서 작성된 `app.py` 코드를 절대 훼손하거나 임의로 생략(`# ... 기존 코드 생략 ...` 절대 금지)하지 말고, 현재 Phase의 기능을 aa완전한 실행 가능 코드로 통합하여 `app.py`에 반영합니다.
3. **자동 코드 검증 (Verification)**:
   - 코드를 저장한 직후 터미널 도구로 `python3 -m py_compile app.py`를 실행하여 문법 에러(SyntaxError, IndentationError 등)가 없는지 검증합니다. 에러 발생 시 즉시 수정합니다.
4. **`progress.md` 업데이트 및 다음 단계 안내**:
   - 검증을 통과하면 `progress.md` 파일에서 해당 Phase의 상태를 `- **진행 상태**: [x] 완료`로 수정하여 저장합니다.
   - 사용자에게 현재 완료한 Phase 요약과 함께, **"다음 Phase X를 진행할 때는 모델 Effort를 [Medium/High]로 설정한 뒤 계속 진행을 지시해 주세요"**라고 안내하고 즉시 턴을 종료합니다.
